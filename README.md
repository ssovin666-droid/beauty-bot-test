# Beauty Bot — бот-заглушка для Фазы 1 теста

Минимальный рабочий бот: разделы «Полка» и «Вишлист», добавление товаров текстом,
кнопка «включить уведомления». Реальных уведомлений не шлёт — это заглушка для
проверки гипотез, а не финальный продукт. Ровно то, что описано в плане запуска.

## 1. Получить токен бота (5 минут, без разработчика)

1. Открой Telegram, найди **@BotFather**
2. Отправь `/newbot`, придумай имя и username (должен заканчиваться на `bot`, например `beauty_bot_test_bot`)
3. BotFather пришлёт токен вида `123456789:AAH...` — это и есть `BOT_TOKEN`

## 2. Запустить бота

Нужен Python 3.10+ на любом компьютере или сервере.

```bash
pip install -r requirements.txt
export BOT_TOKEN="вставь_сюда_токен_от_botfather"
python bot.py
```

На Windows вместо `export` используй `set BOT_TOKEN=...`.

Пока эта команда выполняется — бот работает. Закроешь терминал/выключишь
компьютер — бот остановится. Для реального теста с рекламой это не подходит,
нужен хостинг (шаг 3).

## 3. Куда захостить, чтобы бот работал постоянно

Самый простой бесплатный вариант для такого маленького бота — **Railway** или **Render**:

1. Зарегистрируйся на railway.app или render.com
2. Загрузи туда эту папку (через GitHub — можно просто загрузить файлы в новый репозиторий)
3. В настройках проекта задай переменную окружения `BOT_TOKEN` со своим токеном
4. Команда запуска: `python bot.py`

Бесплатного тарифа обоих сервисов достаточно для теста на 2–3 недели с несколькими
сотнями пользователей. Если понадобится помощь с самим деплоем — можно попросить
отдельно, это можно сделать за один созвон с любым разработчиком за 15–20 минут.

## 4. Ссылки с указанием источника (UTM-аналог для Telegram)

У Telegram-ботов свой механизм вместо UTM-меток — параметр `start` в ссылке.
Формат ссылки:

```
https://t.me/твой_бот_username?start=ИСТОЧНИК
```

Например, для теста из плана:

- `https://t.me/beauty_bot_test_bot?start=vish_vk` — таргет ВК, ветка Вишлист
- `https://t.me/beauty_bot_test_bot?start=polka_vk` — таргет ВК, ветка Полка
- `https://t.me/beauty_bot_test_bot?start=vish_yandex` — Яндекс Директ, ветка Вишлист
- `https://t.me/beauty_bot_test_bot?start=polka_yandex` — Яндекс Директ, ветка Полка
- `https://t.me/beauty_bot_test_bot?start=vish_blogger_ivanova` — конкретный блогер

Именно эту ссылку с нужным `start=` вставляешь в объявление/пост у блогера —
бот сам запомнит источник для каждого пользователя.

## 5. Как считать метрики

- Быстро, прямо в Telegram: команда `/stats` в самом боте (для тебя как админа)
  покажет общее число регистраций и активных
- Подробно, по каждому источнику отдельно: на сервере, где крутится бот,
  выполни `python stats.py` — выведет таблицу: источник → регистраций →
  активных → конверсия

«Активный пользователь» = добавил минимум 2 товара (на полку и/или в вишлист)
И включил уведомления — это ровно определение из юнит-экономической модели.
Порог легко поменять: переменная `ITEMS_THRESHOLD` в начале `bot.py`.

CAC бот не считает сам, потому что не знает, сколько потрачено на рекламу —
это число берёшь из рекламного кабинета и делишь на регистрации по нужному
источнику из таблицы `stats.py`.

## Файлы в этой папке

- `bot.py` — сам бот
- `stats.py` — подсчёт метрик по источникам
- `requirements.txt` — зависимости для `pip install`
- `beauty_bot.db` — появится сама при первом запуске, база данных SQLite
